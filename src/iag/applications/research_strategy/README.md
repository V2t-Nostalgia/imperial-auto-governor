# 科研战略 Application

该 Application 把存档中的已完成科技、当前研究和三系候选分开，并只允许选择
最新同步存档明确列出的候选。原版 `common/technology` 只补充领域、成本、层级、
前置和效果证据，绝不自行创造候选。

`062d` 开始研究与 `4533` 停止研究已经有 Stellaris 4.4.6 非房主请求/房主回传
成对样本。当前仍作为默认关闭的实验能力：空研究槽只发送一次开始命令；切换进行
中的科技必须由玩家另行启用，并严格执行“停止旧科技、确认、开始新科技、确认”。

`conversation_agent.py` 提供独立科研模型回路，`prompts/research_director_zh.md` 规定其
只能处理三系合法候选。该 Agent 使用独立模型绑定和历史，不再借用经济 Agent 的工具
回路；网页“对话对象”可直接选择科研战略 Agent。
