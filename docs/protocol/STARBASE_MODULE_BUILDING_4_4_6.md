# Stellaris 4.4.6 恒星基地模块与建筑建造

本文记录四次完整的非房主请求与房主权威广播配对：空模块槽 0 建造 `shipyard`，空建筑
槽 0 建造 `crew_quarters`，在同一建筑槽中把 `crew_quarters` 替换为
`hydroponics_bay`，以及在同一模块槽中把 `shipyard` 替换为 `anchorage`。四次捕获均
只观察网络，没有运行数据包改写器。

## 共同外层

两类动作都使用 `b43d01000300` 建设命令族，并共享：

| 标签 | 样本值 | 含义 |
|---|---:|---|
| `822c01001400` | 0 | 当前玩家／命令上下文 |
| `634001001400` | 8371 | 恒星基地建设队列 ID |
| `632c01000c00` | 0 | 所属命名空间中的槽位索引 |
| `0c3a01001400` | 104 | 目标 `starbase_mgr.starbases` 条目 |

`632c` 不是建设队列中的排队位置。船坞尚在建时，船员居住舱仍以 `632c = 0` 追加到
同一队列；模块槽 0 和建筑槽 0 通过不同子类型区分。

## 模块与建筑差分

| 项目 | 模块 | 建筑 |
|---|---|---|
| 选择 | `shipyard` | `crew_quarters` |
| 子类型标记 | `ca3d01000300` | `c93d01000300` |
| ID 字符串标签 | `193a01000f00` | `1a3a01000f00` |
| ID 长度 | 8 | 13 |
| 记录长度 | 138 | 143 |
| 应用总长度 | 141 | 146 |
| 客户端 serial | 91 | 94 |
| 房主 serial | 45827 | 45859 |

两组请求与各自房主回包在清零 command serial 后均逐字节相同。记录长度的 5 字节差与
脚本 ID 长度差一致；除子类型标记、ID 标签和动态字符串外，两个请求的业务结构相同。

因此可以分别实现参数化构造器，而不需要为每个模块或建筑保存整包模板：

1. 从存档读取当前玩家、恒星基地、建设队列和空闲槽索引；
2. 从匹配游戏版本的原版规则与 Content Pack 枚举合法 ID；
3. 模块写入 `ca3d/193a`，建筑写入 `c93d/1a3a`；
4. 写入对应命名空间的槽位索引和目标恒星基地条目；
5. 根据 ASCII ID 长度重算记录长度和应用 framing。

## 已验证的建筑替换

在已建成的建筑槽 0 中把 `crew_quarters` 替换为 `hydroponics_bay` 时，线路命令仍使用
`b43d/c93d/1a3a`，`632c` 仍为 0。记录只携带新建筑 ID，不包含旧建筑 ID，也没有额外
的拆除确认或替换模式字段。请求与房主广播仍然只在 command serial 上不同。

| 项目 | 空槽建造 | 已占用槽替换 |
|---|---|---|
| 新建筑 | `crew_quarters` | `hydroponics_bay` |
| 建筑槽 | 0 | 0 |
| 记录长度 | 143 | 145 |
| 应用总长度 | 146 | 148 |
| 客户端 serial | 94 | 103 |
| 房主 serial | 45859 | 52579 |

两条记录的长度差恰好来自新建筑 ID 的长度差。因此，线路协议不单独表达“替换”；房主
根据命令执行时目标槽位是否已有建筑决定实际效果。

## 已验证的模块替换

在已建成的模块槽 0 中把 `shipyard` 替换为 `anchorage` 时，线路命令仍使用
`b43d/ca3d/193a`，`632c` 仍为 0。记录只携带新模块 ID，不包含旧模块 ID，也没有
额外的拆除确认或替换模式字段。请求与房主广播仍然只在 command serial 上不同。

| 项目 | 空槽建造 | 已占用槽替换 |
|---|---|---|
| 新模块 | `shipyard` | `anchorage` |
| 模块槽 | 0 | 0 |
| 记录长度 | 138 | 139 |
| 应用总长度 | 141 | 142 |
| 客户端 serial | 91 | 106 |
| 房主 serial | 45827 | 52584 |

长度差同样恰好来自新模块 ID 的长度差。因此，模块与建筑的替换都复用各自的普通建设
命令，槽位在房主当前状态中是否已占用才决定实际语义。

自动化执行前必须从最新存档或机器事实账本确认槽位状态：

- 空槽可以直接建设合法建筑；
- 已占用槽只有在玩家启用相应替换能力且规划明确要求时，才允许发送新模块或建筑 ID；
- 不得依据旧捕获推断当前槽位仍由同一模块或建筑占用；
- 模块和建筑使用彼此独立的槽位命名空间，不能跨类型复用槽索引判断。
