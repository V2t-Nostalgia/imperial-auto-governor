# Stellaris 4.4.6 科研选择记录

本文件记录用于回归测试的结构结论，不包含会话地址、端口、完整抓包或用户路径。

## 已确认字段

| 偏移 | 含义 |
|---:|---|
| `0` | 记录声明长度低 8 位；高 8 位来自三字节应用前缀的第 3 字节 |
| `1..5` | 固定记录 envelope `0004000000` |
| `6..11` | `062d01000300` 开始研究，或 `453301000300` 停止研究 |
| `18..27` | actor 标签和 32 位 actor |
| `45..51` | origin 标签和 1 字节 origin |
| `52..61` | command serial 标签和 32 位 serial |
| `70..79` | `822c` context 标签和国家对象 |
| `80..87` | `072d` 科技标签和 16 位 ASCII 长度 |
| `88..` | 科技 ID，随后是 `04000400` 尾部 |

完整长度规则见 `APPLICATION_COMMAND_FRAMING_4_4_6.md`。当前科研记录长度是
`92 + len(technology_id_ascii)`；现有科技 ID 尚未使它跨过 256 字节，但解析器仍不得
把记录首字节误解为完整的 16 位长度。构造器只接受受限科技标识符，并在构造后重新解析
核对 action、context 与科技 ID。回包关联要求命令族、完整目标、来源 actor 和 origin
同时匹配。
