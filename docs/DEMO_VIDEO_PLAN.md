# 演示视频脚本

建议制作 8 到 12 分钟的无剪辑核心演示，并另附一段架构说明。

1. 展示启动器、版本、许可证和空白战役会话。
2. 房主创建新档，Host Bridge 上传首份自动存档。
3. 前端把该存档绑定到玩家选择的战役会话。
4. 编写十年计划，展示紧急状态可覆盖并由玩家手动结束。
5. 展示模型读取资源、殖民地、建设队列并生成多个合法候选。
6. 连续执行两项建设，分别展示包确认和存档确认状态。
7. 启用联网检索，展示来源 URL，同时说明网页文本不能直接控制游戏。
8. 展示上下文压缩前后统计，确认完整历史仍可查看。
9. 结束时展示 commit、签名 Tag、四个独立归档、顶层 SHA-256 校验和与 Release 页面。

录制前必须新建演示专用 API 密钥和游戏身份。画面中不得出现真实密钥、令牌、证书私钥、私人 IP、Steam 好友列表、个人路径或未脱敏存档。
