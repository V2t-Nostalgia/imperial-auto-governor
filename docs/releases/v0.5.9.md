# v0.5.9 Draft

本版本用于公开测试，不应被视为最终稳定版。

## 新增

- 保留 `carrier_click` 稳定默认模式。
- 新增可选 Windows `session_proxy`，可在一局连接中自主插入已验证建设命令。
- 新增动态长度建筑、基础区划和区域特化构包。
- 新增 `fleet_operations` Application、舰队存档视图、军力与可用性解析。
- 新增舰队总开关、攻击总开关和逐舰队移动/攻击权限。
- 新增已完成真实闭环验证的 `d32c` 舰队移动工具。
- Windows Agent 冻结包包含会话代理 worker、PyDivert DLL 与驱动。

## 兼容性修复

- 修复 v0.5.8 根级扁平模型配置无法启动 v0.5.9 Windows Agent 的问题。
- `base_url`、`model`、API Key 文件以及旧版请求参数会先在内存中迁移；只有玩家显式保存模型配置时才改写磁盘文件。
- 冻结版 `--health-check` 现在同时验证新版模型池配置与 v0.5.8 扁平配置。
- 修复 `session_proxy` 只按手填房主 IP 监听、导致 Steam 公网/中继会话永远无法锁定可靠流的问题。
- 会话代理发现阶段现会动态读取本机 Stellaris 与 Steam 进程的 UDP 端口归属；锁定后仅接管实际对端四元组。

## 安全边界

- 会话代理默认关闭，需要管理员权限和玩家显式确认。
- 代理必须在合作端进房前启动并保持到离房后。
- 新舰队默认不授权。
- `6b33` 舰队攻击尚未完成成对验证，因此本版拒绝构造或发送攻击命令。
- 模型自然语言不能把动作标记为成功；权威回包或后续存档才是机器事实。

## 测试重点

- 公网、局域网和 Steam Relay 条件下的整局代理稳定性。
- 同一连接中的多次建设与舰队移动。
- 24 位可靠流 offset 回绕后的 sender epoch 处理。
- 合作玩家重同步、掉线和重新进房时必须重新启动代理。
- 舰队毁灭、MIA、交战与所有权变化后的权限失效。
